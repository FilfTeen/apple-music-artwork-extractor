# 支持范围与已知限制

当前版本为 0.5.1，需要 Python 3.11+。默认 Web provider 使用实验性 Apple Music Web 接口，服务返回的字段可能变化；一次查询或下载成功只覆盖该资源、地区、语言、响应和支持的素材布局。

## 支持的功能

| 范围 | 当前行为 |
| --- | --- |
| 资源 | playlist、album、artist、song；single、EP、compilation 使用 album 资源族 |
| 静态图片 | 发现、语义选择、尺寸约束、下载与实际图像解码；保留色彩声明和解码证据 |
| 动态封面 | 检查 HLS 档位；下载符合完整单 MP4 布局的原始字节，核对媒体信息并完整解码 |
| 任务管理 | 预检、资料库查询、明确版本、编号接续、原目录恢复、有界诊断与取消 |
| 版本比较 | 离线比较明确版本；按原来源和选择范围只读检查远端声明 |
| 调用方式 | 中文终端、可选 Rich 界面、单 JSON 结果及独立 JSONL 事件通道 |

静态功能只依赖 Pillow。动态检查需要 `motion` extra；动态下载还需要本机 FFmpeg 与 ffprobe。终端 `ui` extra 只改变呈现，不改变下载或验证能力。

## 平台

下载功能面向 macOS 和 Linux，文件提交需要 POSIX 目录描述符、no-follow 和文件锁能力；Windows 下载目前不支持。

macOS 和 Linux 均可在 Python 3.11+ 的虚拟环境中安装发行包，并按需添加 `ui` 或 `motion` 依赖；动态下载还需自行安装适合本机的 FFmpeg 与 ffprobe。安装步骤见 [README](../README.md#安装)，当前版本变化见 [v0.5.1 发行说明](https://github.com/FilfTeen/apple-music-artwork-extractor/releases/tag/v0.5.1)。

终端按当前宽度渲染，支持中文文本、纯文本、无颜色和重定向。不同终端的字体、字符宽度与窗口缩放表现仍可能不同。

## 媒体与数据限制

- 动态下载仅支持已结束、无加密、连续区间覆盖同一个完整 MP4 的布局。多文件 HLS、直播、加密、低延迟部分分片、未知编码和无法确认连续性的时间轴不支持。
- 工具不转码、不下载音乐、不处理 Apple ID 登录、私人资料库、私人播放列表认证或 DRM 绕过。
- 最大可验证 rendition 不等于原始母版；PNG 不自动证明更多细节或 P3。冲突或不足的色彩证据保留为未核实。
- 图片上限为 32 MiB／4000 万像素，单视频上限为 256 MiB。
- 字段未返回、null、空值、异常和未知观察分别记录。未返回素材不证明远端实际不存在，未知候选和未验证内容会阻止完整标记。
- 远端更新检查只观察资源信息和必要的 HLS/HEAD。地址变化不证明内容变化，声明相同不证明媒体字节相同，服务器错误标注响应类型仍可能突破基于声明的正文边界。
- 官方 catalog provider 属于实验性功能，需要使用者自己的开发者 token；真实认证兼容性尚未确认，不保证覆盖所有资源、地区和语言组合。

## 恢复与兼容边界

普通恢复继续保存的快照；需要获取新版时显式使用 `--new-version`。完成文件必须通过长度、SHA-256、请求约束和验证策略核对才能复用，修改或损坏的文件保留并报冲突。未完成文件从头重取，不做字节范围续传。v0.5.1 首次接续旧验证策略的视频时执行本地 probe 与完整解码，不重新下载；成功后再次接续只需常规本地核验。原下载验证记录不改写，新策略的完整证据单独保留。

任务列表和详情只读。损坏条目单独报告，损坏的版本登记可能阻止同库任务接续；不能通过删除锁、覆盖记录或重新分配版本绕过检查。旧状态只有在身份可可靠重建时才允许兼容导入。

命令成功仍须检查 `coverage`、警告、逐项结果和 `manifest_report`。明确跳过可使命令结束，但不会把原选择范围标为全部完成。
